# Global LLM Logs

This folder contains project-wide LLM traces. These are generated by `backend/htbmc/app.py`.

## `llm_prompts.jsonl`

Written by:

- `_record_llm_prompt()`
- `_record_llm_response()`

Each line is a JSON object. Prompt events include:

- `id`
- `event`
- `timestamp_utc`
- `model`
- `ip_address`
- `target_id`
- `system_prompt`
- `user_prompt`
- `operator_prompt`

Response events reuse the prompt `id` and add:

- `response.content`
- `response.queued_action_ids`
- `response.attached_context`
- `response.model_error`

Example inspection:

```bash
tail -n 20 state/logs/llm_prompts.jsonl
curl -s 'http://127.0.0.1:8000/api/llm/prompts?limit=20'
```

## `llm_planner.jsonl`

Written by:

- `_run_planner_step()`
- `_llm_agent_worker()`

Each line records one planner run, skip, or error. Important fields include:

- `timestamp_utc`
- `target_id`
- `trigger`
- `skipped`
- `reason`
- `prompt_id`
- `queued_action_ids`
- `model`
- `error`

Example inspection:

```bash
tail -n 50 state/logs/llm_planner.jsonl
curl -s 'http://127.0.0.1:8000/api/llm/trace?limit=20'
```

## LLM Analysis Guidance

Use `/api/llm/trace` when the backend is running because it joins prompt, response, planner, and target conversation context. Parse raw JSONL directly only when the backend is down or when you need exact historical lines.
